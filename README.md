# SEL Platform Data

SEL 教師專業發展平台的第一批資料、分類索引與 MVP 原型。

## 分類

- 評量工具與量表
- 教學活動與教案
- 學術文獻與實證
- 研習模組與講師素材
- SEL 五大核心能力
- 教育階段
- 108 課綱相關資訊

## 自動化

修改主資源 CSV 後，GitHub Actions 會重新產生分類索引與 JSON：

- `SEL平台規劃/12_SEL主分類索引.csv`
- `SEL平台規劃/13_依資源類型索引.csv`
- `SEL平台規劃/14_依SEL五大能力索引.csv`
- `SEL平台規劃/15_依教育階段索引.csv`
- `SEL平台規劃/16_108課綱對應索引.csv`
- `SEL平台規劃/17_SEL分類索引.json`

> 目前資料是建庫種子資料。部分資源仍待直接頁面、授權、研究或信效度查核，正式發布前請依查核狀態使用。
