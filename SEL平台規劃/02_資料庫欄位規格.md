# SEL 平台：資料庫欄位規格

## 一、核心資料實體

```text
來源 Source
  └─ 資源 Resource ──< 資源版本 ResourceVersion
                    ├─< SEL能力對應 SkillMapping
                    ├─< 課綱對應 CurriculumMapping
                    ├─< 審查紀錄 Review
                    ├─< 使用案例 Case
                    └─< 使用回饋 Feedback

使用者 User ──< 學習活動 LearningActivity ──< 反思 Reflection
學校 School ──< 實施方案 Implementation ──< 成效紀錄 Outcome
```

## 二、來源 Source

| 欄位 | 型別 | 必填 | 說明 |
|---|---|---:|---|
| source_id | UUID | 是 | 唯一識別碼 |
| name | 字串 | 是 | 機構或網站名稱 |
| country_region | 字串 | 是 | 國家／地區 |
| source_type | Enum | 是 | 政府、學校、大專校院、研究機構、非營利組織、商業機構 |
| official_url | URL | 是 | 官方來源 |
| contact_url | URL | 否 | 聯絡或授權頁 |
| source_owner | 字串 | 否 | 內容擁有者 |
| credibility_level | Enum | 是 | 官方、學術、專業組織、現場實踐、待查 |
| last_verified_at | 日期 | 是 | 最後查核日 |
| notes | 長文字 | 否 | 查核備註 |

## 三、資源 Resource

| 欄位 | 型別 | 必填 | 說明 |
|---|---|---:|---|
| resource_id | UUID | 是 | 唯一識別碼 |
| title_zh | 字串 | 是 | 中文標題 |
| title_original | 字串 | 否 | 原文標題 |
| summary | 長文字 | 是 | 100–300 字摘要 |
| resource_type | Enum | 是 | 框架、研究、課程、教案、活動、影片、工具、案例、政策 |
| target_role | 多選 | 是 | 導師、科任、輔導、行政、師培者、家長 |
| education_stage | 多選 | 是 | 幼兒園、國小、國中、高中職、大專、跨階段 |
| age_range | 字串 | 否 | 適用年齡 |
| duration_minutes | 整數 | 否 | 課堂或研習時間 |
| language | 多選 | 是 | 中文、英文、其他 |
| localization_status | Enum | 是 | 未在地化、已翻譯、專業審查、現場試用、正式推薦 |
| evidence_level | Enum | 是 | 系統性回顧、實驗／準實驗、相關研究、專家共識、現場案例、未查證 |
| accessibility | 多選 | 否 | PDF、Word、簡報、影片字幕、無障礙版本 |
| license_type | Enum | 是 | CC、公開授權、需申請、僅連結、未知 |
| source_id | FK | 是 | 所屬來源 |
| status | Enum | 是 | 草稿、審查中、已發布、封存 |
| keywords | 多選 | 否 | 關鍵詞 |
| created_at / updated_at | 日期時間 | 是 | 系統欄位 |

## 四、SEL 能力對應 SkillMapping

| 欄位 | 說明 |
|---|---|
| framework | CASEL、OECD、RULER、臺灣自訂框架 |
| domain | 五大能力或其他框架面向 |
| sub_skill | 例如情緒辨識、衝動控制、觀點取替、溝通、決策 |
| evidence_note | 為何判定對應此能力 |
| mapping_confidence | 高、中、低 |

## 五、課綱對應 CurriculumMapping

- curriculum_version：課綱版本
- education_stage：教育階段
- learning_area：學習領域
- core_competency：核心素養
- issue_integration：議題融入
- learning_performance：學習表現
- content：學習內容
- mapping_note：對應說明
- reviewer_id：審查者

## 六、案例 Case

應包含 school_context、student_context、identified_need、objectives、intervention、duration、participants、teacher_actions、student_response、adaptations、outcomes、limitations、transfer_conditions、attachments、consent_status。案例中的學生資料預設去識別化，照片、作品與逐字稿須另存同意紀錄。

## 七、審查 Review

- review_id、resource_id、reviewer_role、reviewer_name_or_code
- review_dimensions：內容正確性、年齡適切性、文化適切性、教學可行性、心理安全、版權
- score、recommendation、concerns、required_revision
- reviewed_at、next_review_at

## 八、教師使用與學習紀錄

只保存完成專業發展所必要的資料：user_id、resource_id、activity_type、started_at、completed_at、reflection、self_reported_application、badge_or_certificate。學生個別心理或情緒資料不應放在一般教師資源資料庫；若有研究需求，必須進入獨立且受控的研究資料環境。

## 九、資料治理規則

- 每筆資料須有來源、授權、版本、查核日與責任人。
- 個資採最小化、目的限定、角色分權與操作留痕。
- 研究工具標示信效度、適用對象、翻譯／授權狀態與限制。
- 內容修改採版本控制，舊版本不得直接覆寫。
- 3–6 個月檢查外部連結、政策版本與資源可取得性。
- 評量資料以形成性回饋為原則，不作為教師個人績效排名。
