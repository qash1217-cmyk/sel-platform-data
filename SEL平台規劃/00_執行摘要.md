# SEL 平台規劃執行摘要

## 建議定位

本平台定位為「SEL 教師專業學習與實踐支持系統」，不是單純教材下載網站。核心循環是：理解概念 → 選擇情境 → 備課 → 班級實施 → 反思 → 同儕共備 → 累積案例。

## MVP 先做什麼

優先完成資源目錄、檢索篩選、教師學習路徑、教案工作台、反思紀錄與內容審查後台。先以 2–3 個高需求情境、3–5 所試點學校與 100 筆審查資源驗證，不宜一開始蒐集所有學校與所有心理資料。

## 主要決策

- CASEL 五大能力可作為跨國共同分類；另建立臺灣課綱、教育階段與文化情境對照。
- 資源卡片必須同時有來源、版本、授權、證據、適用條件與審查狀態。
- 學生資料與一般教學資源分區，學生個別心理資料不得混入普通資料庫。
- 評量用於形成性回饋與方案改進，不用於教師個人排名或單一績效判斷。
- 臺灣在地案例應與國外研究並列，但清楚標示其證據性質，避免把經驗案例誤稱為成效證據。
