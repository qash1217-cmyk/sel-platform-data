# SEL 平台：MVP 功能需求書

## 一、產品目標

讓教師能在一個可信、可搜尋、符合臺灣教育情境的平台完成「學習—備課—實施—反思—共備」，並讓學校累積可傳承的 SEL 專業實踐知識。

## 二、角色與權限

| 角色 | 主要權限 |
|---|---|
| 一般教師 | 搜尋、收藏、學習、下載授權資源、提交反思與案例 |
| 輔導／專業教師 | 建立與審查資源、帶領社群、查看彙整回饋 |
| 學校管理者 | 管理校本方案、指派學習路徑、查看去識別化統計 |
| 縣市／中央管理者 | 管理政策資源、審查流程、跨校彙整 |
| 研究／內容審查者 | 審查證據、適切性、版權與研究資料 |
| 系統管理者 | 帳號、權限、備份、稽核、系統設定 |

## 三、MVP 必要功能

### F1 資源目錄與搜尋

- 關鍵字全文搜尋。
- 依教育階段、年級、角色、SEL 能力、課綱、時間、資源類型、證據等級與授權篩選。
- 顯示摘要、適用情境、來源、版本、授權、審查狀態與推薦理由。
- 支援收藏、分享連結與下載紀錄。

### F2 教師學習路徑

- 入門、班級經營、教師自我覺察、課程融入、全校推動五類路徑。
- 每條路徑由閱讀、影片、實作、反思、課堂應用組成。
- 顯示進度、完成條件與可選的研習證明。

### F3 教案／活動工作台

- 依課程模板建立教案。
- 自動帶入 SEL 能力、課綱、時間與材料欄位。
- 允許教師複製、改編、標記版本與保存個人備註。
- 清楚顯示可否改編與再分享。

### F4 案例與反思

- 以引導問題記錄需求、策略、學生反應、調整與下一步。
- 案例可設定草稿、校內分享、公開分享。
- 送出前檢查個資、照片、學生姓名與版權風險。

### F5 審查與內容治理

- 多階段審查：內容、教學、文化／心理安全、版權。
- 支援退回修改、審查意見、版本比較與重新審查。
- 資源逾期或連結失效提醒。

### F6 基本分析

- 資源瀏覽、收藏、下載、完成率與教師回饋。
- 以群組彙整呈現，不顯示個別教師排名。
- 管理者可匯出去識別化報表。

## 四、第二階段功能

- 與教師研習／單一登入系統整合。
- 校本 SEL 方案與跨校社群。
- 個人化推薦與能力地圖。
- 課堂觀察工具、學生匿名回饋與行動研究模組。
- API、行動版、字幕與無障礙支援。

## 五、非功能需求

| 類別 | MVP 要求 |
|---|---|
| 安全 | HTTPS、角色權限、管理員 MFA、操作稽核、備份與復原測試 |
| 隱私 | 個資最小化、去識別化、同意紀錄、資料保存期限 |
| 效能 | 常用搜尋結果 3 秒內回應；支援至少 500 同時使用者的初期容量目標 |
| 可用性 | 響應式網頁、清楚的繁體中文、鍵盤操作與字幕欄位 |
| 維運 | 錯誤監控、連結檢查、版本控制、內容審查 SLA |
| 可擴充 | API-first、資料匯出、模組化內容模型、可替換搜尋引擎 |

## 六、MVP 驗收指標

- 100 筆以上完成審查的示範資源。
- 至少 5 條教師學習路徑。
- 至少 3 個教育階段與 5 種教師角色有可用內容。
- 80% 試用教師能在 3 分鐘內找到適用資源。
- 70% 試用教師能完成一份教案或反思紀錄。
- 100% 公開資源有來源、版本、授權與審查狀態。
- 試辦學校能產出一份去識別化的實施摘要。
