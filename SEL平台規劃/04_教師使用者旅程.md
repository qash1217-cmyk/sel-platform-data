# SEL 平台：教師使用者旅程

## Persona：國小導師／科任教師

需求：想處理班級衝突與學生情緒，但時間有限，且不確定 SEL 如何連結課程；希望看到同年段可直接使用、經過審查的資源。

| 階段 | 教師行為 | 主要痛點 | 平台設計回應 | 成功訊號 |
|---|---|---|---|---|
| 觸發 | 發現班級衝突、低落或合作困難 | 不知道從哪裡開始 | 首頁提供情境入口：「情緒調節」「同儕衝突」「班級關係」 | 找到符合情境的入口 |
| 探索 | 以年級、時間、情境搜尋 | 資源很多但品質不一 | 顯示審查、證據、授權、所需時間與教師評語 | 3 分鐘內找到 3 筆候選 |
| 理解 | 閱讀摘要、看示範影片 | 理論難轉成行動 | 每筆資源提供「本節課怎麼做」「教師引導語」「注意事項」 | 能說明目標與流程 |
| 備課 | 收藏、複製教案、調整活動 | 課程與班級情境不同 | 可改編模板、課綱對照、材料清單、版本紀錄 | 產出可用教案 |
| 實施 | 在班級使用活動 | 學生反應可能不同 | 提供課前提醒、替代方案、心理安全與轉介提示 | 完成一次實施 |
| 反思 | 記錄學生反應與教師感受 | 沒時間寫長篇報告 | 3–5 題快速反思、語音／短文字、私人或分享設定 | 完成反思並提出下一步 |
| 共備 | 與同年級或輔導人員討論 | 經驗難傳承 | 校內社群、案例留言、共編與版本比較 | 形成一次同儕回饋 |
| 持續成長 | 依需求進入下一課程 | 不知道自己的成長方向 | 依收藏、反思與自評推薦下一個學習單元 | 完成學習路徑 |

## 關鍵使用情境

### 情境一：10 分鐘內找一個明天可用的活動

首頁 → 選「國小／同儕衝突／30 分鐘內／可直接使用」→ 查看審查與材料 → 收藏 → 下載教案 → 課後快速反思。

### 情境二：教師想改善自己的情緒回應

首頁 →「教師自我覺察」學習路徑 → 觀看短課程 → 完成自評 → 設定一週實踐目標 → 反思 → 選擇同儕分享或私人保存。

### 情境三：學校推動共同方案

行政建立校本方案 → 指派學習路徑 → 教師完成共同基礎課程 → 各班實施 → 匯整去識別化回饋 → 召開共備會議 → 更新校本方案。

## 必須避免的體驗

- 首頁只呈現大量檔案，沒有情境導覽。
- 沒有標示授權，教師不敢下載或改編。
- 把教師自評或學生回饋轉為個人排名。
- 讓教師輸入可識別的學生心理或輔導個案資料。
- 要求教師填寫長篇成果報告才可使用資源。
